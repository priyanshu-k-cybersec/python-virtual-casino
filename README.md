# 🎰 Python Virtual Casino Game

A command-line interface (CLI) application built using Python to simulate a virtual casino using virtual coins. This project demonstrates core programming concepts including conditional logic, loops, data structures, random number generation, and menu-driven interaction.

## 🚀 Features

* **Number Guessing Game:** Guess a number between 1 and 10 and win virtual coins based on the game result.
* **Lucky Spin:** Spin the wheel and receive a random multiplier of 0x, 1x, 2x, or 5x.
* **Rock Paper Scissors:** Play against the computer using randomly generated choices.
* **Virtual Coin Balance:** Tracks the player's balance throughout the game.
* **Game History:** Stores and displays previous game results using a Python list.
* **Player Status:** Displays player name, balance, games played, games won, games lost, and win percentage.
* **Random Bonus:** Provides a random virtual coin bonus.
* **Game Over Condition:** Ends the game when the player's balance reaches zero.
* **Exit Option:** Allows the player to exit the game and view final statistics.

## 🛠️ Tech Stack & Concepts Used

* **Language:** Python 3.x
* **Module:** `random`
* **Core Concepts:** Variables, input/output, `while` loops, conditional branching (`if-elif-else`), lists, tuples, dictionaries, string formatting, and basic arithmetic operations.
* **Application Type:** Menu-driven command-line application.

## 🖥️ How to Run

1. Clone or download the repository:

   ```bash
   git clone https://github.com/priyanshu-k-cybersec/python-virtual-casino.git
   ```

2. Navigate to the project directory:

   ```bash
   cd python-virtual-casino
   ```

3. Run the Python file:

   ```bash
   python casino_game.py
   ```

4. Enter your player name and select an option from the main menu.
